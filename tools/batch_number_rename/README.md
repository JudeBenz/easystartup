# Batch Number Rename

Add `1_`, `2_`, `3_`, … in front of every file in a folder.

## Windows
1. Install [Python](https://www.python.org/downloads/) if needed (check **Add to PATH**).
2. Double-click **`Run_Batch_Number_Rename.bat`**
3. Browse to a folder → **Preview** → **Rename files**

## Options
- **Start at** — first number (default `1`)
- **Zero-pad** — `0` = `1_`, `2_` · `2` = `01_`, `02_` · `3` = `001_`, …
- **Skip already numbered** — leaves files that already start with `12_` alone
- **Include subfolders** — optional

Always Preview first. Renames happen on disk immediately after you confirm.
